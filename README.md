# CANSET web sitesi

can-set.com yeniden tasarımı. Astro ile statik site.

```
npm install
npm run dev      # yerel önizleme
npm run build    # dist/ klasörüne derler
```

- Metinler: `src/data/site.js`, referans logoları: `src/data/referanslar.json` + `public/referanslar/`
- Eski (Wix) sitenin ham metin arşivi (TR + EN): `docs/mevcut-site/`
- Renkler logodan: `#1A683C` (koyu yeşil), `#009C2C` (canlı yeşil); tokenlar `src/layouts/Base.astro` içinde.
